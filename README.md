# Peach

### What is Peach?
Peach is a little funtime project of mine I work on in my free time. It probably isn't the most stable
thing in the world. But it works somewhat well enough. It's still in the like pre-pre-pre-alpha stages 
of development.

### What can it do?
Like not much.. at all.. Obviously, this will get out of date relatively quickly, since I probably won't
maintain this readme the most. But at the time of writing this, you can setup a game, with levels, with game
objects, with components. Load 3d models, Add lights, cameras.. and that's actually about it "feature"-wise.
I've spent quite a bit of development time rn on like some ui stuff. it's not final, as it's kinda baked into the 
engine itself rn, which is.. not ideal, to say the least. But for now, I justify it as being a sort of a debug
ui. Next you can save / load levels, gameobjects and etc with just one function call each to a json file with gson.

### How to use?
As of now, your best bet will probably be to look at the testing/development/debug/whatever files in `net.meowsers` to 
see some quick examples. I might try to add some more test/example levels in the future that you could just swap out in
the main file or something. But to actually 'import it' or use it. You can use files from the `net.meowsers.peach` 
package
